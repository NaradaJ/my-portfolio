## The problem

Filling the same PDF template with rows of spreadsheet data by hand is slow, repetitive and easy to get wrong.

## What I built

A Python script that:

- **reads** records from an Excel file,
- **cleans and formats** each value,
- **places** the data onto a PDF template, with custom font sizes for specific fields,
- **writes** a finished PDF.

## Why it matters

It’s the same instinct as my day job: find the repetitive, error-prone step and make it reliable. One run replaces hours of manual entry, and every document comes out consistent.
