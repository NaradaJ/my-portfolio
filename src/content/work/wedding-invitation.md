## The brief

My own wedding invitation: something guests could open from a WhatsApp message on any phone, in Sinhala, that felt personal rather than like a template.

## What I built

- **A single, fast page:** styles and script live inside one `index.html`.
- **Self-hosted Noto Serif and Noto Sans Sinhala**, so the page doesn’t depend on Google Fonts and the Sinhala text renders correctly everywhere.
- **Custom artwork, background music** and an **Open Graph image**, so the WhatsApp link preview looks right.
- **Hosted free on GitHub Pages.**

## What I learned

Small details decide how a page feels: font loading, how the link preview looks, and how the page behaves on a slow phone connection.
